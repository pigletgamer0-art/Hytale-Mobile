# Hytale Mobile

Unofficial community experiment for running a user-provided Hytale Windows client on Android.

This repository contains only the Android launcher/runtime integration and mobile controls. It does **not** distribute Hytale game files.

Current development line: Alpha 0.8, with a standalone Android launcher inspired by the separation used by mobile Java launchers (launcher UI, scoped storage, runtime backend, graphics/input layer).

The current client available to this project is a Windows x86-64 executable, so the Android backend still relies on a compatibility runtime while native alternatives are investigated.

Migrated from the temporary `hytale-mobile` branch that had been created inside `better-xcloud-desktop.`. Hytale Mobile development now lives only in this repository.
